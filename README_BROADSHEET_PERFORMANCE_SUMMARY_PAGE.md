# Broadsheet PDF — Performance Summary Page

The Download PDF broadsheet now keeps the student ledger pages clean and repeats the student column header on subsequent pages. After the final student page, the PDF starts a dedicated new page containing the PERFORMANCE SUMMARY block with:

1. SUBJECT PERFORMANCE
2. CLASS PERFORMANCE
3. STREAM PERFORMANCE
4. GENDER PERFORMANCE
5. CLASS PERFORMANCE LEVEL DISTRIBUTION

The summary is rendered from the same broadsheet population/data used for the student ledger.
