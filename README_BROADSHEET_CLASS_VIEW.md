# Broadsheet — Stream and Whole Class/Grade View

This version adds a **Whole class / grade (all streams)** option to the Broadsheet.

## How to use

1. Open **Broadsheet**.
2. Select any stream belonging to the grade, for example `GRADE 6 NORTH`.
3. In the new view selector choose:
   - **This stream only** — the existing stream broadsheet.
   - **Whole class / grade (all streams)** — combines all streams belonging to the same grade, e.g. Grade 6 North + Grade 6 South.
4. Select the exam type, term and year.

## Data safety

The whole-grade view does **not** create, delete, merge, or move exams, subjects, or results. It reads each learner's existing exam for their own stream. If a subject is not offered in a particular stream, that learner's cell is shown as `—` and is not counted as a missing mark.

Existing stream broadsheets continue to work as before.
