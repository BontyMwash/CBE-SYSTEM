# Marks Entry Setup Screen

Before entering marks, every user must choose:

1. Exam (exam type + term + year)
2. Class
3. Stream
4. Subject
5. Out of (paper maximum)

The marks grid stays hidden until a valid exam/class/stream/subject combination is selected. The chosen `Out of` value is saved to the selected exam before the marks grid opens.

Stream selection resolves to the exact class/stream label already used by the existing exam and student records, so marks continue to save against the correct sitting.
